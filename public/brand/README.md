# norte brand pack

The pack exports the compass mark already used by the norte website. The source
SVG files are the masters; PNG and ICO files are derived exports.

## Which file to use

- `svg/norte-symbol.svg`: primary symbol, transparent background.
- `svg/norte-symbol-dark.svg`: app/profile icon on the norte dark background.
- `svg/norte-symbol-light.svg`: app/profile icon for light contexts.
- `svg/norte-symbol-black.svg` and `norte-symbol-white.svg`: one-colour use.
- `svg/norte-wordmark-*.svg`: horizontal lockups for dark, light, or transparent contexts.
- `png/`: raster exports at common production sizes.
- `favicon/`: browser favicon, SVG favicon, and Apple touch icon.

## Colours

- Phosphor: `#B7FF52`
- Base: `#07090A`
- Ink: `#F1F5EF`
- Light-context ink: `#132015`

Keep clear space around the mark equal to at least one quarter of its diameter.
Do not rotate the mark, recolour individual parts, or place the transparent
version on a background where its contrast is weak.

The wordmark uses Inter Semi Bold with a system sans-serif fallback. For exact
rendering where Inter is unavailable, use the supplied PNG export.
